## 逆向工具链

早期为了分析固件，写了一批 Python 工具（未随仓库发布，需要时可以按 `notes/` 里的描述重建）：

- `vdex` / `cdex` 解析、quickened dex 反汇编（Android 8 的 `vdex006` 校准过 59/59 方法）
- `axml` 二进制 manifest 解析与回写
- APK 内 `classes.dex` 提取、`odex`/`vdex` 分离

> 注意：设备上的 `services.vdex` 是 **CompactDex（`cdex001`）**，不能直接套标准 dex 解析器。
> 需要按 `vdex019` 头 → `cdex` 头的顺序解析。
