## 分区（`/dev/block/by-name`）

| 名称 | 设备 | 说明 |
|---|---|---|
| boot | `mmcblk0p8` | 48 MB，`ANDROID!` 头，kernel 约 13.7 MB，无 ramdisk |
| recovery / hirecovery | `mmcblk0p9` / `mmcblk0p24` | 恢复分区 |
| system | `mmcblk0p29` | 3 GB，`/dev/root`，ext4，挂载为 `/`（ro） |
| vendor | `mmcblk0p27` | 400 MB |
| data | `mmcblk0p31` | 约 24 GB，ext4（rw） |
| cache | `mmcblk0p26` | 100 MB |

`/system` 是 **纯 ext4、没有 dm-verity**，所以 `mount -o remount,rw /` 可以直接改（这也是写系统应用的前提）。

## 怎么自查

```console
adb shell getprop ro.product.device          # NOVA72691
adb shell getprop ro.build.version.incremental  # 04.02.60.03
adb shell getprop ro.build.version.security_patch
adb shell uname -a
adb shell getenforce
adb shell cmd package query-activities --brief -a android.intent.action.MAIN -c android.intent.category.HOME
```

> 同型号但软件版本不同（比如 `04.02.60.01`，Android 8）的机器，行为可能完全不同，别直接套用。
