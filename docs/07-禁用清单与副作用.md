# 07 · 禁用清单与副作用

去广告/精简最常见的事故不是"禁错了开不了机"，而是**禁了某个包之后，某个功能悄悄坏了**，过很久才发现。
这篇记录本机禁用了什么、以及哪些包**绝对不能碰**。

> 这不是"推荐禁用清单"。同一台机器上，禁用会影响保修、OTA 和功能完整性。想跟着做请自己逐条评估。

---

## 一、最容易被误伤的几个（按踩坑顺序）

| 包名 | 是什么 | 禁掉之后的症状 |
|---|---|---|
| `com.jamdeo.tv.livetv` | 直播 / 信号源画面的承载应用 | **切 HDMI/AV 信号源时闪一下就跳回桌面**，像"切换失败"。本机实际踩过：电脑接 HDMI 完全连不上，恢复这个包立刻正常 |
| `com.hisense.tv.tiletransition` | 信号源切换的过渡/落地 | 切换静默失效：按了没反应，也不报错 |
| `com.hisense.tv.inputs` | 信号源面板（选 HDMI1/HDMI2…） | 遥控器"信号源"键无反应 |
| `com.hisense.tv.globalui` | 音量条、输入提示等全局 UI | 音量条不显示、切源没有提示 |
| `com.android.bluetooth` | 蓝牙 | 蓝牙遥控器/蓝牙音箱/蓝牙耳机失效 |
| `com.hisense.tv.mirror` | 手机投屏 | 投屏入口消失 |
| `com.jamdeo.screensaver` | 屏保 | 待机屏保不出现（不影响开机） |

**判断方法**：功能坏了先别怀疑硬件，按这张表对一遍 `pm list packages -d`。

---

## 二、本机踩过的具体案例（HDMI 连不上）

现象：电脑用 HDMI 接电视，遥控器选信号源 → 画面闪一下 → 回到桌面，看起来像"切换被拒绝"。

排查过程：

```console
# 1) 看禁用列表里有没有输入源相关的
adb shell pm list packages -d | grep -E "livetv|tile|inputs"
# package:com.jamdeo.tv.livetv        ← 命中

# 2) 看它的状态
adb shell dumpsys package com.jamdeo.tv.livetv | grep -m1 "User 0:"
# User 0: ... enabled=2 ...   （2 = disabled）

# 3) 恢复
adb shell pm enable com.jamdeo.tv.livetv
# Package com.jamdeo.tv.livetv new state: enabled

# 4) 再切一次信号源 → 正常显示电脑画面
```

结论：`livetv` 是 VIDAA 上承载输入源画面的应用，禁用它等于把"切过去之后显示什么"删掉了，
所以系统切过去又弹回桌面。

> 顺带说明：恢复只需要 `pm enable`，不需要 root，也不需要重启（本机验证：立即生效）。
> 这个状态写在 `/data/system/users/0/package-restrictions.xml` 里，**重启后保持**。

## 三、我们的做法：能不禁就不禁，用 force-stop 代替

聚好看（`com.jamdeo.tv.vod`）我们**没有禁用**，因为：

1. 禁用它的桌面组件会让开机永远走不完（见 [02-为什么换桌面这么难.md](02-为什么换桌面这么难.md)）；
2. 禁用整个包会牵连它的服务，行为不可预测。

用的是：

```console
adb shell am force-stop com.jamdeo.tv.vod
```

只杀进程、保留包和组件，开机时系统会重新拉起，再被开机钩子切走。这样内存省了（约 180 MB），
但"包是完整的"这件事没变，随时可以恢复。

---

## 四、安全的精简流程

1. **一次只禁一个**，禁完立刻验证对应功能；
2. 每次禁用前记下包名和"它是什么"，写进自己的清单；
3. 优先用 `pm disable-user --user 0 <pkg>`（可逆），不要动 `/system` 里的文件；
4. **永远不要禁用**：`com.hisense.tv.inputs`、`com.hisense.tv.tiletransition`、
   `com.jamdeo.tv.livetv`、`com.hisense.tv.globalui`、以及任何 `com.android.providers.*`；
5. 出问题先 `pm enable` 回来，再考虑别的。

恢复某一条：

```console
adb shell pm enable <包名>
adb shell pm list packages -d        # 确认它已经不在禁用列表里
```
